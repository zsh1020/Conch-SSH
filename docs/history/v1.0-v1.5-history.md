### 11.4 后端实现细节

**`backend/sftp/client.go`**

```go
type SFTPClient struct {
    sshClient *ssh.Client          // 复用已有 SSH 连接
    client    *sftp.Client         // github.com/pkg/sftp
}

// 通过已有 SSH 连接创建 SFTP 子会话
func NewSFTPClient(sshConn *gossh.Client) (*SFTPClient, error) {
    c, err := sftp.NewClient(sshConn)
    // ...
}
```

> **关键**：SFTP 复用同一个 `*gossh.Client`，不新开 TCP 连接。

**`backend/sftp/ops.go`**

```go
type FileInfo struct {
    Name    string `json:"name"`
    Size    int64  `json:"size"`
    Mode    string `json:"mode"`     // "-rwxr-xr-x"

    IsDir   bool   `json:"is_dir"`
}
```

**进度推送方式**（通过 Wails Events）

```go
// app.go 中上传/下载调用示例
func (a *App) SFTPUpload(connID, localPath, remotePath string) error {
    // ...
    transferID := uuid.New().String()
    progressFn := func(done, total int64) {
        runtime.EventsEmit(a.ctx, "sftp:progress:"+transferID,
            map[string]int64{"done": done, "total": total})
    }
    return sftpClient.Upload(localPath, remotePath, progressFn)
}
```

> 前端通过 `EventsOn("sftp:progress:{transferID}", cb)` 接收进度更新。

### 11.8 注意事项

1. **SFTP 懒加载**：不是每个 SSH 连接都需要 SFTP，在用户第一次切换到文件视图时才初始化 `sftp.NewClient()`，失败时提示「服务端不支持 SFTP」
2. **递归上传/下载**：暂不实现目录递归，三期仅支持单文件；递归操作留给五期
3. **本地路径**：Windows 下路径分隔符为 `\`，Go 后端用 `filepath` 包处理，避免硬编码
4. **大文件**：进度推送频率控制在每 500ms 最多一次，避免频繁 IPC 影响性能
5. **Wails 绑定**：新增方法后必须运行 `wails generate module` 重新生成 TS 绑定
6. **connEntry 扩展**：`app.go` 中的 `connEntry` 结构需增加 `sftp *sftpbackend.SFTPClient` 字段

### 12.5 Goroutine 模型

```
StartTunnel(connID, TunnelConfig):
  ctx, cancel = context.WithCancel(appCtx)
  listener = net.Listen("tcp", localAddr)
  go accept loop:
    conn, _ = listener.Accept()
    go handleConn(ctx, sshClient, conn, remoteAddr)
  
handleConn:
  remote = sshClient.Dial("tcp", remoteAddr)  // 本地转发
  go io.Copy(remote, conn)
  io.Copy(conn, remote)
  
StopTunnel(tunnelID):
  cancel()  → listener.Close() → 所有 goroutine 退出
```

### 12.6 ProxyJump 实现

在 `backend/ssh/client.go` 的 `Dial` 中，若 `sess.ProxyJump != ""` 则先 dial 跳板机，再通过跳板机的 `conn.Dial("tcp", targetAddr)` 进行第二层 SSH 握手：

```go
if sess.ProxyJump != "" {
    bastion, _ = dialSSH(bastionAddr, bastionCfg)
    netConn, _ = bastion.Dial("tcp", targetAddr)
    // 在 netConn 上做目标机器 SSH 握手
}
```

## 16. v1.3 功能说明

### 16.1 密码 AES-256-GCM 加密存储

**原理**：密钥 = `SHA-256(hostname + homeDir)`，无需外部 keychain 依赖。

```go
// backend/config/keystore.go
func Encrypt(plaintext string) (string, error)  // 返回 base64(nonce + ciphertext)
func Decrypt(b64 string) (string, error)
```

**迁移策略**：`sessions.go` 的 `save()` 中使用写时复制（copy-on-write），对内存中的 `Password` 不做修改，只在写盘前加密副本；`load()` 读取后就地解密，历史明文数据自动兼容。

---

### 16.2 主机指纹变更告警

`knownhosts.Manager` 新增 `HostKeyChangedFunc` 回调类型：

```go
type HostKeyChangedFunc func(host, oldFingerprint, newFingerprint string) bool
```

检测到 `knownhosts.KeyError`（`Want` 非空）时触发回调。`app.go` 中实现为弹出 `runtime.WarningDialog`，用户选「信任新指纹」返回 `true`，Manager 随即调用 `removeHost()` 删除旧条目、`append()` 写入新条目。

`removeHost(hostname)` 实现：逐行读取 `known_hosts`，检查每行第一字段（逗号分隔的主机列表）是否包含目标主机名，过滤后重写文件。

### 16.5 服务器状态监控

**采集命令**（单次 SSH channel，`; true` 保证 exit 0）

```go
const collectCmd = `sh -c 'cat /proc/stat 2>/dev/null; printf "\nGSSH_MEM\n"; ` +
    `cat /proc/meminfo 2>/dev/null; printf "\nGSSH_NET\n"; ` +
    `cat /proc/net/dev 2>/dev/null; true'`
```

**输出分割**：按哨兵 `"\nGSSH_MEM\n"` 和 `"\nGSSH_NET\n"` 分三段，各段独立解析，单段失败不影响其他段（返回 0 值）。

**CPU 计算**：两次采样取增量 `(total - idle) / total × 100`，首次调用只保存基准，返回 0。

**网络计算**：累加所有非 lo 接口的 rx / tx 字节，两次采样除以时间差得速率（bytes/s）。

**Goroutine 管理**

```go
// app.go
type App struct {
    monitorMu   sync.Mutex
    monitorStop map[string]chan struct{}
}

func (a *App) StartMonitor(connID string) error  // 启动 ticker goroutine
func (a *App) StopMonitor(connID string)          // 关闭 stopChan 退出 goroutine
```

**事件推送**：每 2 秒 `runtime.EventsEmit(ctx, "monitor:stats:"+connID, stats)`

**数据结构**

```go
type MonitorStats struct {
    CPU      float64 `json:"cpu"`
    MemUsed  uint64  `json:"mem_used"`
    MemTotal uint64  `json:"mem_total"`
    NetRx    float64 `json:"net_rx"`   // bytes/s
    NetTx    float64 `json:"net_tx"`   // bytes/s
    Error    string  `json:"error,omitempty"`
}
```

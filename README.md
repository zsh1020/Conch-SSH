# 🐚 Conch

> **Every shell, in one shell.**
>
> 基于 Go + Wails v2 的现代化跨平台 SSH / SFTP 桌面客户端 —— 多标签终端、文件管理、服务器监控、端口转发、本地终端，一壳搞定。

---

## 功能特性

### 核心终端
- **xterm.js** 终端渲染，支持全彩 256色、Unicode、Emoji
- **多标签页**管理，Ctrl+T 新建、Ctrl+W 关闭、Ctrl+Tab 切换、Ctrl+1~9 跳转
- 终端内搜索（Ctrl+F，实时高亮，上/下导航）
- 右键菜单：复制 / 粘贴 / 全选 / 清屏
- PTY 尺寸自动同步（ResizeObserver）

### SSH 连接
- 支持**密码 / 私钥（PEM） / SSH Agent** 三种认证方式
- **ProxyJump 跳板机**支持（`[user@]host[:port]` 格式）
- TOFU 主机指纹验证（首次连接弹窗确认，写入 `~/.ssh/known_hosts`）
- **主机指纹变更告警**：指纹变化时弹出警告对话框，用户可选择信任或拒绝连接
- 30 秒保活心跳，防止空闲断连
- 密码字段 **AES-256-GCM 加密存储**（机器指纹派生密钥，`enc:` 前缀标识）

### 会话管理
- 会话列表按**分组**树形展示，支持折叠/展开
- **分组拖拽排序**：hover 分组标题出现 `⠿` 手柄，拖拽调整顺序并持久化
- 侧边栏宽度拖拽调整（160–480px，重启后记忆）
- 搜索过滤（会话名 / 主机 / 用户名）+ **Tag 标签筛选**（多选 AND 逻辑）
- **「⏱ 最近」分组**：最近使用的 5 条会话，显示相对时间
- **会话收藏（★）**：常驻金色星标，收藏状态持久化
- 右键菜单：连接 / 编辑 / 收藏 / 删除
- 从 `~/.ssh/config` **一键导入**会话

### 文件管理（SFTP）
- 终端与文件面板**同时显示**（左终端 + 右文件面板，拖拽分隔线调整宽度）
- 文件列表：多列排序、可配置显示字段、**按后缀显示不同图标**（🖼️🎬🎵📦📜⚙️ 等）
- **路径栏可直接输入跳转**：点击路径 → 输入框，Enter 导航，Esc 取消
- 系统文件选择框上传（支持多选）+ 拖拽上传
- 下载目录记忆，系统目录选择框浏览
- 文件预览：文本 / 图片 / 二进制三类渲染（右键菜单「预览」触发）
- 右键菜单：预览 / 下载 / 用本地编辑器打开 / 重命名 / 删除
- 本地编辑器集成：文件保存后弹出「是否上传」对话框

### 端口转发
- 本地转发 `-L`、远程转发 `-R`、SOCKS5 动态代理 `-D`
- 规则管理 UI：添加 / 停止，并发连接计数
- SSH 断开时自动停止全部隧道

### 效率工具
- **命令片段（Snippet）**：预设常用命令，按分组管理，支持 `{变量:默认值}` 参数占位符，一键发送
- **批量广播**：同时向多个标签页发送相同命令，支持 Tab 多选
- **服务器状态监控**：CPU / 内存 / 网络实时仪表板（每 2 秒刷新，60 秒历史折线图）
- **端口转发预设库**：MySQL / PostgreSQL / Redis / MongoDB / Kubernetes / SOCKS5 等常用规则一键填入
- **断线自动遮罩**：连接断开时显示「重新连接 / 关闭标签」，一键重连复用上次参数
- **标签页拖拽排序**：鼠标拖拽调整标签顺序
- **快捷键速查面板**（`?`）：全部快捷键分类一览

### 个性化设置
- 深色 / 浅色主题实时切换
- 终端字体族 / 字号 / 光标样式 / 闪烁 / 回滚行数设置
- SSH 密钥生成（Ed25519 / RSA-4096），公钥一键复制

## 快速开始

### 下载

从 [Releases](https://github.com/zsh1020/Conch-SSH/releases) 页面下载最新版 `conch.exe`，双击运行，无需安装。

> **系统要求**：Windows 10/11 x64（需 WebView2 运行时，Windows 11 已内置）

### 从源码构建

```bash
# 1. 克隆仓库
git clone https://github.com/zsh1020/Conch-SSH.git
cd Conch

# 2. 安装依赖
go mod tidy
cd frontend && npm install && cd ..

# 3. 开发模式（热更新）
wails dev

# 4. 生产构建
wails build
# → build/bin/conch.exe
```

**构建依赖**

| 工具 | 版本 | 说明 |
|------|------|------|
| Go | 1.22+ | https://go.dev/dl/ |
| Node.js | 18+ | https://nodejs.org/ |
| Wails CLI | v2.12.0 | `go install github.com/wailsapp/wails/v2/cmd/wails@latest` |
| WebView2 | 最新 | Windows 11 已内置 |
| TDM-GCC | 任意 | Windows CGO 编译器 |

## 使用说明

### 连接服务器

1. 侧边栏点击 **「＋」** 新建会话，填写主机/端口/用户名/认证方式
2. 双击会话或右键→「连接」，新标签页中打开终端
3. 无需保存时点击标题栏 **「快速连接」** 按钮临时连接

### 快速命令片段

1. 标签栏右侧点击 **📋** 按钮，打开片段下拉面板
2. 点击「管理」进入 CRUD 对话框（支持按分组归类）
3. 面板中点击 **▶** 按钮，命令即刻发送到当前终端

### 批量广播

1. 标签栏右侧点击 **📢** 按钮，激活广播模式
2. 顶部广播条中勾选目标标签页（默认全选已连接）
3. 在输入框输入命令，按 Enter 或点击「发送」

### 服务器监控

1. 标签栏右侧点击 **📊** 按钮，打开监控面板
2. 自动开始采集 CPU / 内存 / 网络数据，每 2 秒刷新
3. 关闭面板后自动停止后台采样

> 监控通过 SSH exec 读取 `/proc/stat`、`/proc/meminfo`、`/proc/net/dev`，仅支持 Linux 服务器。

### 端口转发

1. 连接后点击 **🔗** 按钮，打开转发面板
2. 点击「＋ 添加规则」，选择转发类型（本地 / 远端 / SOCKS5）
3. 填写本地地址和远端地址，点击「启动」

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+T` | 新建标签页（快速连接） |
| `Ctrl+W` | 关闭当前标签页 |
| `Ctrl+Tab` | 切换到下一个标签页 |
| `Ctrl+Shift+Tab` | 切换到上一个标签页 |
| `Ctrl+1~9` | 跳转到第 N 个标签页 |
| `Ctrl+F` | 终端内搜索 |
| `Esc` | 关闭搜索栏 / 弹窗 |
| `?` | 打开 / 关闭快捷键速查面板 |

## 数据存储

所有数据存储在用户目录下，无注册表依赖：

| 文件 | 说明 |
|------|------|
| `~/.config/conch/sessions.json` | 会话配置（密码字段 AES-256-GCM 加密） |
| `~/.config/conch/settings.json` | 应用设置（主题、字体等） |
| `~/.config/conch/snippets.json` | 命令片段 |
| `~/.ssh/known_hosts` | 主机指纹记录 |
